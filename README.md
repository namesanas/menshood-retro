# MENSHOOD Retro

Standalone retro-style fashion catalogue with animated disco lights, three supplied portraits, and demo products. Separate from the professional Menshood storefront.

## Run

Open `dist/index.html` in a browser. No installation or build step is required.

## Edit

- `dist/index.html`: page content and CSS.
- `dist/app.js`: demo product names, prices, and enquiry behaviour.
- `dist/assets/`: supplied photos.

Upload the contents of `dist/` to a static web host. This repository alone does not activate website hosting.

The catalogue is a demo. Enquiry buttons show a local notice; no orders or payments are submitted. Use Pause lights to stop animations. Reduced-motion preferences are supported.
